Course overview

Fundamental concepts and techniques of computer programming using a high-level, object-oriented programming language. Topics include problem solving, algorithm design, arrays, searching and sorting, classes and objects, encapsulation, inheritance and polymorphism, exception handling, file input and output, abstract classes and interfaces, recursion, and the use of systems software.

Prerequisite: CPS 1231. See the syllabus summary for learning outcomes, course expectations and student support.

Learning objectives

Upon successful completion of the course, you will be able to:

  1. Define and describe computing and programming concepts.
  2. Implement a computing-based solution using appropriate programming constructs.
  3. Apply a problem-solving process and design algorithms.
  4. Design, code, execute, test, debug and document programs in a high-level, object-oriented language.

Course topics

  • Problem solving and algorithm design
  • Arrays, searching and sorting
  • Classes, objects and encapsulation
  • Inheritance and polymorphism
  • Abstract classes and interfaces
  • Exception handling
  • File input and output
  • Recursion and systems software
